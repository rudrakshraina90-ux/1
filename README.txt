MKB Corporation site (mkbcorporation.in)
=========================================
- Upload everything in this folder to the repository root. GitHub Pages ignores .htaccess and _headers; they only matter on Apache / Netlify / Cloudflare Pages.
- CNAME contains mkbcorporation.in (needed for the GitHub Pages custom domain).
- Analytics: open assets/analytics.js and paste your GA4 Measurement ID (G-XXXXXXXXXX) into GA_ID. Empty = analytics off.
- Images: a few images are loaded from lh3.googleusercontent.com. Download them into assets/ and update the links (see index.html and assets/app.js).
- After going live: submit https://mkbcorporation.in/sitemap.xml in Google Search Console.
